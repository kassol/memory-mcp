# Design System: 记忆登记簿 (Memory Registry)

The console uses shadcn/ui as shipped: the `radix-nova` style, the neutral base color, Geist Variable, lucide icons. There is no custom visual layer on top. Components in `web/src/components/ui/` are generated by the shadcn CLI (`pnpm dlx shadcn@4.23.0 add <name>`) and kept as generated; a change of look happens through the theme variables in `web/src/index.css` or by regenerating, never by editing a component's classes.

The earlier "records registry" direction (custom ledger tokens, outlined stamps, ruled rows; 2026-10-30) is retired.

Source of truth: `web/components.json`, `web/src/index.css` (theme variables for light and `.dark`), `web/src/components/ui/`.

## Theme

- Light and dark come from shadcn's neutral theme. `next-themes` sets the `.dark` class; the default follows the system, and the sidebar footer cycles 跟随系统 / 浅色 / 深色 (stored in `localStorage`).
- No custom colors. Status uses `Badge` variants: `secondary` for current, `outline` for archived, finding kinds and conflict merge, `default` for correction and for a value set in the console. Destructive actions use the `destructive` button variant or `text-destructive`.
- Monospace (`font-mono`) only for entity keys and setting keys; times use `tabular-nums`.

## Layout

- Shell: `SidebarProvider` + `Sidebar collapsible="icon"` (header with the product mark, a "跳转或检索" item with `⌘K`, the five pages, footer with appearance and sign out) + `SidebarInset`. `⌘B` toggles the sidebar. On phones (below 768px) the sidebar is a sheet opened from the trigger in each page header.
- Page header: `SidebarTrigger`, a vertical `Separator`, the page title, page-level facts on the right (count of open findings, total records).
- Docket: a list of cases (bordered buttons with the case number, a kind badge and a two-line detail) in a 20rem column, and the case on the right: heading with kind badge, the check's opinion, the record cards (two columns from `xl` for a pair), a `Separator`, the ruling row with "判为误报", and `Kbd` shortcut hints. On phones the list and the case are separate views with "返回列表".
- Records: search input with an icon, key filter, type `Select` (with counts), then a bordered `Table` (TanStack Table, server-side sorting and paging; sortable headers are ghost buttons with an arrow icon), then "第 n / m 页" with 上一页 / 下一页. Phones hide the two time columns. A row opens a right `Sheet` with the record card and its version history.
- Settings: a short intro, then one `Card` per group (行为参数, 高级参数). Each setting is a row: label, key, source badge, description, recommended value and evaluation note on the left; input with 保存, range or `FieldError`, an `Alert` when a tuning value differs from its recommendation, and outline restore buttons on the right.
- Sign-in: centered `Card` on `bg-muted` with the product mark above it; three views keyed separately: 登录 (admin password), 首次登录 (configuration-file access token, only while no password exists), 设置管理口令 (password twice).
- Settings has two tabs: 参数 (the setting cards) and 安全 (change password; sign out every device, destructive).

## Components

- Record card: `Card` with `CardHeader` (monospace key as title, written / valid from / version count as description, status badges as `CardAction`), `CardContent` (full text, line breaks kept, never truncated; archive reason), `CardFooter` (改正 as `outline`, 归档 as `ghost` with destructive text). Correct and archive open a `Field` form inline in the footer: textarea or input, description of what will change, 取消 (`ghost`) and the confirm button (`default`, or `destructive` for archive).
- Version history: bordered list items with time, status and mutation badges, and the text; older versions in `text-muted-foreground`.
- States: `Skeleton` while loading, `Alert variant="destructive"` with 重试 on errors, `Empty` with an icon for empty views and pages not built yet.
- Toasts: `sonner` via the shadcn `Toaster`, bottom center.
- Command palette: `CommandDialog` with a 页面 group and, after two characters, a 记忆 group of search results.

## Rules

- Memory text is untrusted: render it as text only. ESLint rejects `dangerouslySetInnerHTML` and `innerHTML` everywhere, including generated components.
- Show the full memory text in cards and history; only list rows and table cells clamp to two lines.
- One primary (`default`) button per decision point.
- Interface language is Chinese; strings inside generated components that users can see or hear (screen-reader labels such as 关闭, 切换侧栏) are translated in place.
